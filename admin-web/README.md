# Cetaring Admin Web App

This app is the second platform app: the **Admin Operations Console**.

## Features

- Secure admin login
- Live order monitoring with status updates
- In-app + browser notifications for new pending orders
- Upload and manage offers
- Upload and manage events/campaigns
- Dashboard metrics for orders and revenue

## Setup

```bash
npm install
```

## Run

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Environment

Create `.env`:

```env
VITE_API_URL=http://localhost:8080/api
```
